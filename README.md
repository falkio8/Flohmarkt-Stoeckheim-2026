# Flohmarkt Stöckheim – Spielzeug-Planer

Interaktive Karte für den Flohmarkt in Stöckheim mit Schwerpunkt auf Spielzeugständen.

## Funktionen

- alle erfassten Stände auf einer Karte
- klare Spielzeugangebote rot markiert
- mögliche Treffer wie Spiele oder Puzzle orange markiert
- übrige Stände grau dargestellt
- Suche nach Adresse oder Angebot
- Filter für Spielzeugstände
- Standortanzeige und automatische Tourenreihenfolge
- dauerhaft hinterlegte Standkoordinaten

## Nutzung

Die veröffentlichte GitHub-Pages-Seite im Browser öffnen. Für die Standortfunktion muss der Browserzugriff auf den aktuellen Standort erlaubt werden.

## Hinweise

Die Angaben basieren auf der veröffentlichten Standliste. Positionen und Warenangebote können unvollständig oder kurzfristig geändert sein. Die vorgeschlagene Tour ist eine geografische Näherung und keine straßengenaue Navigation.

## Kartendaten

Die Kartenansicht verwendet OpenFreeMap beziehungsweise OpenStreetMap-Daten. Die jeweilige Quellenangabe wird direkt in der Karte angezeigt.
