# Flohmarkt Stöckheim – Planer

Interaktive Karte für den Straßen- und Garagenflohmarkt in Stöckheim. Sie hilft dabei, interessante Stände zu finden, Favoriten zu speichern und eine persönliche Tour zu planen.

## Funktionen

- zwei Ansichten: **Alle Stände** und **Spielzeug**
- intelligente Suche mit verwandten Begriffen, zum Beispiel für Kleidung, Haushalt oder Fahrräder
- Schnellfilter für Warenkategorien
- wahlweise **Treffer hervorheben** oder **nur Treffer anzeigen**
- Suchtreffer werden auf der allgemeinen Karte rot und größer dargestellt
- eigener Spielzeug-Reiter mit klaren Treffern und möglichen Grenzfällen
- Favoriten und Favoriten-Tour
- Stände als besucht markieren und ausblenden
- Tour aus den aktuell gefilterten Treffern
- optionaler Startpunkt über den aktuellen Standort
- dauerhaft hinterlegte Standkoordinaten
- für Desktop und Smartphones optimiert

## Nutzung

Die veröffentlichte GitHub-Pages-Seite im Browser öffnen. Über die Suche oder die Kategorien lassen sich passende Stände hervorheben. Mit **Tour aus Treffern** wird aus den aktuellen Suchergebnissen eine geografisch sortierte Route erstellt.

Favoriten und besuchte Stände werden lokal im verwendeten Browser gespeichert. Für die Standortfunktion muss der Browserzugriff auf den aktuellen Standort erlaubt werden.

## Hinweise

Die Angaben basieren auf der veröffentlichten Standliste. Positionen und Warenangebote können unvollständig sein oder sich kurzfristig ändern. Die vorgeschlagene Tour ist eine geografische Näherung und keine straßengenaue Navigation.

## Kartendaten

Die Kartenansicht verwendet OpenFreeMap beziehungsweise OpenStreetMap-Daten. Die jeweilige Quellenangabe wird direkt in der Karte angezeigt.

## Projektdatei

Die Anwendung besteht aus einer einzelnen `index.html` und kann direkt über GitHub Pages veröffentlicht werden.
